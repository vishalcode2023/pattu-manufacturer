# Pattu Pavada / Pattu Langa Manufacturer Website

A premium, production-quality React + Vite + Tailwind CSS website for a South
Indian traditional ethnic-wear manufacturer.

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Site configuration

The live site URL defaults to `https://www.pattupavadas.com` in
`src/config/site.js`. Override it with `VITE_SITE_URL` for the client build or
`SITE_URL` when generating the prerendered SEO pages and sitemap.

Business details are in `src/config/site.js`, route metadata and structured
data are in `src/config/seo.js`, and image mappings are in
`src/config/images.js`.

## Design system

- **Palette:** warm ivory, cream, deep wine/maroon, muted gold, charcoal, warm brown
- **Type:** Cormorant Garamond (display) + Manrope (body)
- **Signature motif:** the "zari rule" — a thin gold diamond-repeat divider
  used throughout, echoing the woven gold border on a finished pattu garment
