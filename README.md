# Pattu Pavada / Pattu Langa Manufacturer Website

A premium, production-quality React + Vite + Tailwind CSS website for a South
Indian traditional ethnic-wear manufacturer.

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Before you launch — replace these placeholders

All business-specific details are centralised in two files so you can find
and replace them in one pass:

- `src/config/site.js` — brand name, WhatsApp number, phone, email, Instagram URL
- `src/config/images.js` — every image on the site (currently neutral
  placeholder photography); swap in your own manufacturing and product
  photography here
- `index.html` — canonical URL, Open Graph image URL, and the
  `YOUR_DOMAIN.com` / `YOUR_BRAND_NAME` placeholders in the structured data

Nothing else needs to change — every component reads from these two config
files, so a single edit updates the whole site.

## Design system

- **Palette:** warm ivory, cream, deep wine/maroon, muted gold, charcoal, warm brown
- **Type:** Cormorant Garamond (display) + Manrope (body)
- **Signature motif:** the "zari rule" — a thin gold diamond-repeat divider
  used throughout, echoing the woven gold border on a finished pattu garment
